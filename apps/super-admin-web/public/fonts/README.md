# Super admin fonts

Outfit and JetBrains Mono are served locally with stable family names in
`globals.css`, so generated Next.js font classes cannot drift between HTML and
CSS during development rebuilds.

- Outfit: Latin variable WOFF2, normal, weights 100–900.
- JetBrains Mono: Latin variable WOFF2, normal, weights 100–800.

Both fonts use the SIL Open Font License; the licenses are included here. These
are the same font assets used by the institution portal. Upstream sources are
maintained in google/fonts under ofl/outfit and ofl/jetbrainsmono.
