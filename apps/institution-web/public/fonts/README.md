# Institution portal fonts

These local variable WOFF2 files are the same Google Fonts Latin subsets previously
served by Next.js. Stable family names in globals.css avoid mismatches between
generated font classes in HTML and CSS during development rebuilds.

- Outfit: normal, weights 100–900, licensed under the SIL Open Font License.
- JetBrains Mono: normal, weights 100–800, licensed under the SIL Open Font License.

The corresponding licenses are included alongside the font files. Font sources
and license originals are maintained in google/fonts under ofl/outfit and
ofl/jetbrainsmono.
