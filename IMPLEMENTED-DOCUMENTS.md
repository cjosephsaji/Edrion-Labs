## Request / fee semantics

- Non-fee: normal submit → route → SLA.
- Fee: **atomic draft request + fee invoice/items**; registrar routing and SLA start only on **payment confirmation**; unpaid 72h abandonment unchanged.
- Post-payment decline: flag `refund_flagged` / Fees desk — documents never move money.

## Signer / verify

- New codes: `base32(HMAC-SHA256(DOCUMENT_VERIFY_SECRET, 'v1:'+vaultId))[0..12]` alphabet `[A-HJ-NP-Z2-9]`, `verify_code_version=1`.
- Legacy request-id HMAC codes remain **lookup-verifiable** (never regenerated by migration).
- Projection: issuer name/logo, doc-type label, initials (or full name iff setting on), issue date, status `Valid|Revoked|Superseded`. Constant 404 for unknown/sample; light timing equalization; no PDF/reg no/owner id.
- Preview QR uses `SAMPLE-0000` → same 404 shape.

## State machines

### `document_renders.status`
`queued → rendering → done|failed` (unchanged processor on `documents.render` / reports queue).

### `document_batches.status`
`draft → generating → (report_card only: review → signing) → delivering → completed|completed_with_errors`; cancel only from `generating`.

### `document_batch_items.status`
`pending|rendering|rendered|failed|excluded|delivered` — mirrors render; retry enqueues **fresh** renders for failed only.

### Vault delivery
- `delivered_at` null until sign/desk/publish.
- Abandoned send-backs hidden from student list.
- Superseded rows hidden when `superseded_by` set; student sees “Updated {date}” on successor.
