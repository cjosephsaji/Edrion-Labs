# Living Learning Studio — M4 design

An editorial learning desk: warm paper, deep forest ink, fine rules, oversized concept typography, and a mint stage. A compact Edrion/Petros masthead replaces portal navigation inside V2. Objective and a horizontal three-phase trail establish place. Petros lives at the leading edge of the stage, in the same band as the current instructional prompt, never in a competing sidebar.

Welcome: one featured available/resumable lesson and a compact numbered list of other authorized opportunities. No invented recommendations, memory or achievements.

Explain/demonstrate/explore: one bounded read-only projection of exact public lesson paragraphs, with complete-step controls, progressive emphasis, and side-by-side source excerpts. Existing PresentationController owns progression and companion cues. No inferred diagram relationships or client-issued assessments.

Try: same stage, Petros yields attention, native accessible radio selection boards preserve exact field/choice IDs, and a wide prose response area sits beside the issued passage.

Reflect: exact committed response stays visible. Server evaluation alone supplies criterion status. Pending and teacher review remain distinct; no global success or mastery.

State map: authorized M4 snapshot → presentation adapter → existing timeline → supported companion cue/target. Session status/epoch fences presentation; Ask interrupts at a safe boundary and uses the existing reviewed-source reread command. During assessment, sources/replay/coaching are blocked.

Preferences: compact/hide companion, reduced motion, text-only. Mobile stacks companion prompt, stage and actions in normal document flow. No overlays over student work. Native dialog for sources/help/preferences, focus restoration, keyboard radios, visible focus.

Ownership: usePetrosSession owns durable draft/command/commit/recovery; server owns authority/evaluation. Local reading position is saved only as a step count against current exact source pins; it carries no assessment evidence. Existing server canvas remains independent of the read-only presentation projection and is edited only through accepted commands.

No M5 planner, M6 rig invention, M7 voice, external deployment or provider calls.
