# M3 representative-teacher usability protocol

Status: **pending human testing**. No participants or human completion measurements have been collected. Automated browser timings are separate engineering measurements.

Recruit ten teachers who represent the intended subjects, learner levels, device familiarity and accessibility needs. Assign anonymous participant codes; record consent and accessibility accommodations outside application learning evidence. Use a disposable institution, clean 20-page PDF or 30-slide PPTX, current course mapping, source authorization and independently seeded synthetic qualifications. Qualification turnaround and processing wait are excluded from active review time. Do not use real learner records or grant real academic authority.

Before a participant begins, verify that the exact source/proposal revision has independently qualified teaching, concept and activity decisions and that the intended isolated release mode is eligible. Qualification entry and graph construction must not be participant prerequisites. If source access or mapping blocks the workflow, record a prerequisite failure separately; do not silently repair it during a timed task.

Give this task without coaching: “Select this document for your assigned class and subject. Inspect the learning objectives and one source citation. Preview an activity. Make one wording correction if appropriate, save the draft, request a new independent review when the change invalidates existing decisions, and confirm the exact qualified version’s release status.” Use a second already-qualified proposal for the release-only timing when waiting for the correction’s independent review would otherwise interrupt the task.

Observe source selection, clarity of origin/extraction/semantic status, evidence discovery, understanding of practice versus verification, edit/reorder/remove behavior, stale-save recovery, keyboard focus, activity accessibility and blocked-action messages. Ask the participant to explain whether a citation proves a claim and whether teaching approval approves an assessment answer key. Record assistance, mistakes and confusing labels. Do not score subject mastery or student learning from this exercise.

Success requires selecting and recording the eligible isolated scope receipt without graph editing or moderator task assistance, while correctly distinguishing pending student publication/instrument verification. Record active minutes using an observed stopwatch; pause it only for processing or independent qualification waits. Preserve raw observations rather than estimating time after the fact.
