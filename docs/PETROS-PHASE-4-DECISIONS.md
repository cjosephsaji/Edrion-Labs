# Petros Phase 4 decisions

2 October 2026. Default-off, native institutional synthetic engineering scope; adult English introductory projectile fixture retains Phase 2 decisions. No real authority is created by a fixture.

- Stable journey links existing sessions, companion threads, artifacts and acknowledged workspace checkpoints. Historical IDs remain unchanged; versions/conflicts are explicit.
- A companion question about a currently authorized lesson links its persisted message/thread to that lesson journey through an atomic idempotent receipt. The bounded question becomes the unresolved return request; the transcript remains with the companion owner. Memory changes clear linked questions together with derived summaries/history selection, and old message retries cannot restore them.
- Existing companion preferences own explicit preference values. Optional episodic/hypothesis use starts disabled; corrected/forgotten records advance a memory revision and provider-history cutoff. Sensitive disclosure has no automatic long-term write path. Evidence remains in its immutable owner.
- Synthetic episodic retention: at most 30 days; tentative hypotheses at most 7 days with supporting accepted evidence and confidence. Expiry erases conversational content into content-free tombstones on the next authorized memory/context operation, advances the memory revision and clears summaries. A disconnected device cannot perform server erasure until it reconnects. Real retention/erasure requires institutional/product/privacy authority.
- Forget erases conversational record content, invalidates summaries and future context; content-free tombstones/receipts prevent resurrection. It does not erase separately retained assessment evidence or recall delivered text.
- Recommendations use current authorized accepted objective evidence and existing review due times. Dismissals create no evidence or delivery. Review must use a different eligible task when one exists; absent unseen tasks are disclosed.
- Online, low-bandwidth and durable intermittent private notes are supported targets. Cold offline launch/full packages and authoritative offline answers are unsupported. Disconnected-device revocation cannot guarantee immediate deletion.
- Device storage is bounded to 50 private notes per institution/student, with device sequence and command/version pins. The single cached journey holds identifiers and version pins, excluding source text, conversations, narration, objectives and workspace drafts. A different session cannot reuse that cache. Storage absence, blocked upgrades and failed writes produce an explicit error; browser eviction loses unacknowledged local work and cannot be reversed by the server. Logout/account change clears local owner data when storage is available; a shared device whose storage cannot be cleared needs browser/device cleanup before reuse. Reopening online reauthenticates through normal APIs before reconciliation. Only server-accepted applied/duplicate receipts remove queued notes; conflicts and denials remain readable private drafts for explicit review/discard.
- New Petros guardian sharing stays disabled; independently authorized school services retain their owners. No partner adapter is required by this native journey; existing external authentication/sync gates remain.
- Generated executable extensions remain disabled. Phase 5, deployment and pilot are outside authorization. Educator/curriculum review, live-data policy, physical-device accessibility and pilot authority remain external gates.
